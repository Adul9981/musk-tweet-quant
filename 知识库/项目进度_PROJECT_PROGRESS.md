## 订阅方案（已确认，2026-08-18）

### 模式：TG 用户名名单校验（✅ 已实现）

```text
1. 8/25（含）前为免费体验期，/api/verify-member 一律返回 member=true
2. 8/26 起：用户点"验证会员"输入 TG 用户名 -> /api/verify-member 读取私有 Gist 名单
   （环境变量 MEMBERS_GIST_RAW_URL）匹配并检查 expires -> 前端解锁（localStorage 缓存 24h）
3. 用户付费后，把其 TG 用户名/ID 加入名单并更新 expires；到期改 expires 即可
```

- 为什么最简：不建账号、不接支付平台、不依赖 Bot 群；你只需维护一份名单
- 名单格式参照 `data/members.example.json`；Gist 必须为私有
- 未来（付费用户 100+ 后）：接 Stripe / 支付宝自动续费

### M3 上线前必做（用户侧，8/25 前）

1. 建**私有 GitHub Gist**，内容格式参照 `data/members.example.json`
   （成员字段：tg / id / plan / expires）。
2. 把 Gist 的 raw 链接设置到 Vercel 环境变量 `MEMBERS_GIST_RAW_URL`（告知链接我来配）。
3. 用户付费后把其 tg 用户名（或数字 ID）加进名单并更新 expires。
4. 未配置名单前，8/26 后验证会返回 not_configured，所有用户被当非会员——务必提前配置。
