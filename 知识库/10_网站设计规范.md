# 网站设计规范（SAP / Apple 风格）

> 最高视觉原则（2026-08-18 定稿）：所有页面统一采用 **SAP + 苹果风格**——
> 浅色底、白色圆角卡片、克制的单一强调色、系统字体栈、充足留白、移动端优先。
> 无特殊理由不得偏离。执行前必须对照此文档。

---

## 整体风格

- **风格**：清清爽爽的现代 App，不是炫技、不是信息堆砌
- **原则**：不同颜色 = 不同信号；颜色有含义，不是装饰
- **文字**：能用数字 + 标签表达的，不写长句
- **层次**：卡片式信息层级，白卡片之间用浅分隔线 + 轻阴影区分

## 字体

- 系统字体栈：`-apple-system, BlinkMacSystemFont, "SF Pro Text", "PingFang SC", "Microsoft YaHei", sans-serif`
- 数字优先用等宽：`SF Mono / ui-monospace`
- 圆角：卡片 16px（rounded-2xl）、小元素 8–10px、按钮胶囊形（rounded-full）

## 页面结构（信息架构）

### 导航分组

- **核心功能区（高亮，蓝底胶囊）**：市场概览 · 概率分析 · 发推热力图 · **形态对比**
- **工具区（低调）**：持仓管理 · 推文生成 · 策略指南 · 预警

### 市场概览首页（第一屏 3 秒看懂）

1. 顶部：市场切换胶囊（当前期蓝色高亮）+ 北京时间 + 数据新鲜度
2. 第一行：4 个核心数字（推文数 / 时速 / 剩余时间 / 当前窗口）——白卡片 + 大数字
3. 第二行：预测落点 + 精准度（主数字绿色/蓝色，附距到期说明）
4. 第三行：左 = 本期每日发推热力块；右 = 区间定价（价格 / VR / 盈亏比）
5. 入场信号卡：只有真正有信号时才显示（VR≥1.5 且价格≤20¢），无信号不占空间
6. 今日节奏 & 落点影响 + 24h 发推热力图

### 形态对比页（走势形态预测 · 区间对比分析）

- 独立页面 `public/morphology_compare.html`，主站导航"形态对比"以嵌入方式接入
- 对比 A/B：中心区间 vs 下方 / 上方区间，叠加六种历史形态模板（A–F）
- 保留"条件出现"的隐藏项：推文情况条、相关性提示（最后 24h / 48h）、操作建议卡
- 页面风格与本规范一致（浅色 + 蓝强调色）

### 落地页（Musk Quant Radar）

- 浅色背景、白色卡片、蓝色主按钮
- 功能图标统一为浅蓝底 + 蓝图标，不使用彩色渐变装饰

## 移动端

- 移动端优先：卡片单列、导航横向可滚动、数字行自适应 2 列
- 触控目标 ≥ 36px
